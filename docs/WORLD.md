# 全域カバレッジ

2026-09-25時点の53交易地域・1,303物件を登録。
基本地域・チャプター/DLC地域・大規模地下地域・独立した特殊地域を対象にします。
比較対象の地域一覧は [ESO-Hubのゾーン一覧](https://eso-hub.com/en/zones) です。
一覧にあるBattlegroundsは対戦モードの集合であり、独立した交易地域にはしていません。
個別のダンジョン・試練・プレイヤーハウス・クエスト専用インスタンス、およびESO未実装地域は独立地域の対象外です。

ソルスティスの東西、ハイ・アイルとアメノス、ガレンとイフェロンは地域一覧と同じ単位にまとめています。
ブラックリーチの2洞窟、帝都下水道、真鍮要塞など、別マップの大きな拠点は別地域です。
異界はタムリエル本土とは区別する `atlas="beyond"` のデータを持ちます。

[ナイトマーケットの公式説明](https://help.elderscrollsonline.com/app/answers/detail/a_id/74549/)では期間限定イベント地域ですが、
このミニゲームでは常設の架空交易先です。現実のイベント開催状態・DLC所有権と連動しません。
島や異界へのアクセスはこのゲーム独自の商会規模で解放します。実際の移動先を追加する機能ではありません。

## 物件の作り方

- 元の30件は個別設計の序盤物件・重要本社として維持。
- 各地域に24件ずつ、計1,272件の固定物件を追加。すべて固有IDと固有名を持ち、選択・買収可能な同じモデルを使用。
- 地域の経済環境ごとに8業種を選定。森林は木材・錬金・農業、火山地域は鉱業・鍛造・秘術、地下は鉱業・護送、異界は交易・秘術などを重視。
- 業種の区別に加え、堅実型、高収益高負担型、機動型、資産保全型で利益率・リスク増分・加速度を変える。
- 全物件に地域系列・業種系列を付与。対応する業種には特殊系列も加える。グループの実行機能はPhase 2。
- 駆け引きへの抵抗を保持し、一部業種に完全無効を設定。効果の適用はPhase 3。

量産分は地域別のルールで確定生成するため、全件を手作業で個別執筆したものではありません。
今後、重要な商会・ミッション物件に固有背景と個別バランスを追加します。
生成ルールは固定し、既存セーブのIDが変わらないよう将来の編集ではデータ移行を行います。

## 全件確認

[PROPERTY_CATALOG.md](PROPERTY_CATALOG.md) に全物件の名称・ID・地域・業種・所有・評価額・収益・負担・加速度・経営特性を出力しています。

```sh
luajit scripts/export_catalog.lua
```

地図は8地域ずつ、台帳は8物件ずつ表示し、左右入力でページ送りできます。
1,303件分のコントロールは生成せず、画面の行と地域カードを再利用します。
全地域・物件への参照、固有ID・名称の重複、24件以上の地域別配置、ページ末尾への到達を自動検証しています。

追加参考資料：[原作の物件仕様](https://gcgx.games/rs3/trade_property.html)。
ここから得た設計上の示唆は、物件ごとの独立初期値・増分・推進力・技耐性・複数系列を別々に持たせることです。
原作の物件名・性能表そのものは取り込んでいません。

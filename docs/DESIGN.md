# 設計ノート

## 調査したメカニクスの核

1. **次の一手を作る買収。** 所有物件は得点と資金供給源を兼ねる。地域・品目の組合せが強い共同調達を作るため、安い物件にも戦略的価値がある。
2. **供給源を使い潰す葛藤。** 調達を繰り返すと独立の危険が上がる。大口資金源を温存する判断が、目先の買収と衝突する。
3. **金額以外で流れを変える。** 速度・加速度・待ち時間・物件価値への介入が逆転を作る。忠誠維持の技は共同調達を継続する支えになる。
4. **成長が新しい選択を解放する。** グループの発見と交渉終了時の技習得が、次の買収目標を変える。

## 大人向けの深さ

Phase 5までに実装：

- **流動性と資産を区別。** 総資産は商会現金＋所有物件の評価額。調達用手元資金は物件内部の供給余力として別管理し、二重に総資産へ加算しない。
- **連続要求に逓減。** 同じ交渉内の要求回数が多いほど調達額が減る。所有物件を切り替える判断が生まれる。
- **勢いは時間で失われる。** 資金要求は物件固有の推進力を伴う。資金投入だけの効果は小さく、資金額だけで即時に勝敗を決めない。
- **失敗にも出費。** 何度でも無料で挑み直す手法を避ける。撤退前に消費を明示する。

長期運用で調整する設計：

- 忠誠維持費と根回し、運転資金の回復・留保、集中投資と地域分散の相反。
- 強力な系列連携と、同系列が同時に資金難へ陥る集中リスク。
- 敵の意図の予告、確率と抵抗の表示、失敗から得られる学習。
- 資金を使い切った場合の再建融資と負債返済。単純な待機稼ぎや撤退稼ぎを防ぐ交渉後決算。

負担は交渉間に持ち越し、要求直後に離反判定を行います。Phase 2では交渉後の小回復と有料の暫定根回しを用意し、正式な習得技・抵抗処理はPhase 3で追加します。

買収内部値：`gauge / velocity / acceleration / playerWait / enemyWait`。画面では赤・青の優勢帯の境界だけでゲージ位置を表し、同じ値を示す別の細いバーは置きません。
自社優勢は負方向。範囲は−100～100で、−100が成功、100が失敗です。
数値積分は固定1/60秒、描画フレームの経過は最大0.25秒に制限します。長いフリーズでいきなり決着しない設計です。
150秒で交渉期限切れ＝不成立。結果確定は一度だけです。

調達額：`min(手元資金, (予想収益×係数 + 評価額×係数) / (1 + 要求回数×疲労係数))`。
勢い、資金差からの圧力、速度抵抗は別項目。金額の差は飽和し、速度にも上限があります。

同盟は状態・企業定義にフィールドを用意していますが、調達コマンドは未実装です。
追加要望によりNPCの買収攻撃・防衛戦とランキングを先行実装しました。
攻撃性は攻撃元の選択と発生確率に、買収傾向は標的選択に使用します。防衛性・技嗜好は後続Phaseで使用します。
戦闘中の相手は物件価値と実際の商会現金で制限した予算を一定間隔で投入します。
プレイヤーの買収結果ごとに攻撃判定を一度行い、攻撃があれば防衛、なければ直接ランキングへ進みます。
防衛失敗は所有権を敵へ移します。防衛から次の攻撃は連鎖させません。
資金力ランキングは現金と所有物件の調達余力の合計で並べ、同額なら総資産・固定IDで安定した順序にします。

## 駆け引きのデータ駆動設計

駆け引きは `id / name / cost / effect / learn / resistanceKey` を持ちます。
`effect.type` を加速度、速度、待ち時間、価値倍率、危険度、遅延効果に分け、物件の `negotiationResistances` と照合します。
商人の微笑み・心づけ・悪評・吟遊詩人・正当性・俊足の伝令・偽の伝令・宴席・評議会・市場凍結・席を立つ・離反工作・根回しの13系統をPhase 3で実装済みです。
根回しは農場所有から習得できる主要な安定化手段です。

5章は条件テーブルと解放条件を分離します：資産目標 → ドフォーレ商会本社 → ベールの守護者連合 → 虫の教団 → モラグ・バル コンツェルン。タムリエル外の地域は第5章で初めて解放対象になります。
セーブはスキーマ番号付き状態をアカウント共通SavedVariablesへ保存し、UIコントロールや進行中の交渉は保存しません。静的物件は所有・危険度・調達余力だけを保存し、ESO APIから得た実在地点の定義と物件登録状態は再構築用に保存します。`GetPlayerLocationName` で未登録の実在地点を特定すると、タイトル画面先頭へ登録操作を表示します。決定した時だけ台帳へ登録し、以後は現在地に関係なく通常の交易地図から買収できます。欠損フィールドは現在の初期値で補完します。

真のエンディングは、第5章クリア後に開く100京ゴールドの最終物件「トール・ドライオク」を手動買収すると発生します。ESO APIが公開する実在地点の総数は事前に確定できないため、未知地点を含む全物件所有は条件にしません。トール・ドライオクは現地登録を必要とし、登録後はグレナンブラの交易地図から交渉できます。重要物件として委任とCOMの自動取得から除外します。

ランキングを閉じた時点で決算し、所有物件の予想収益の一部を現金化して調達余力を回復します。再建融資は資金力が閾値未満の場合だけ使え、同額の負債と評判低下を伴います。

敵の買収攻撃は、攻撃性と実際の動員力（現金＋傘下物件の調達余力）から攻撃商会を選びます。章が進むほど発生率、初期拠出、予算、投入速度、加速度、駆け引き頻度が段階的に上がります。対象選択は独立危険度、得意業種、本社、物件価値を評価し、防衛側にとって重要な物件を狙います。敵が使った傘下物件の資金は防衛終了時に実際の準備金から差し引きます。COMのグループ技も実際の構成物件と必要所有数を検査し、構成物件の準備金と独立危険度を代償に発動します。すでに大幅優勢な時は使用せず、章別の確率と回数上限を持つ逆転手段です。自社物件が少ない時は攻撃発生率だけを段階的に下げ、連敗で再建不能になる流れを抑えます。

決算では全1,303物件の評価額と予想収益も複利成長します。自社2.4%、中立2.2%、敵商会2.8%で、敵の再投資速度を最も高く設定しています。買収を遅らせるほど標的価格と敵の資金供給力が増すため、単純な決算待ちは相対的な不利を伴います。キャンペーンに最低期数条件はなく、資産目標50億・2500億・10兆・500兆・100京ゴールドと、章ごとの指定買収を満たした時点で進行します。v0.17.1以降の金額は旧単位の1万倍で、物件と商会の初期額には1万未満の固定端数が付きます。
